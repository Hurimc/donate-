Treo Web 24/24 Với GitHub Pages

Bước 1: Lưu trang web này thành file index.html.

Bước 2: Tạo một **Repository** mới trên GitHub.com (tên repo ví dụ: donate).

Bước 3: Tải file index.html lên và bấm **Commit changes**.

Bước 4: Vào **Settings** -> **Pages** -> Tại mục *Branch* chọn **main** -> Bấm **Save**.

👉 Web của bạn sẽ hoạt động 24/24 hoàn toàn miễn phí!
